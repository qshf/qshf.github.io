一、统一符号表#

「易混对象」一列是重点——很多卡壳来自把这两个记号当成一回事。

符号含义首次出现易混对象 / 提醒
$s,\ \mathcal S$状态、状态空间ch1—
$a,\ \mathcal A(s)$动作、动作空间ch1$\mathcal A(s)$ 带括号：原则上依赖状态；本书统一为同一套 5 动作
$r,\ R$奖励（小写定值/大写随机变量）ch1奖励 $r$ ≠ 回报 $G$
$p(s'\mid s,a)$状态转移概率ch1表格是特例，概率是通用语言
$p(r\mid s,a)$奖励概率ch1—
$\pi(a\mid s)$策略ch1表格策略 vs 参数化 $\pi(a\mid s,\theta)$（ch9）
$\gamma\in[0,1)$折扣因子ch1$\gamma$ 小→短视，$\gamma$→1→远视（ch3.5）
$G_t$回报（从 t 起的折扣奖励和）ch1$G_t=R_{t+1}+\gamma G_{t+1}$（自举关系）
$v_\pi(s)$状态值（在 $s$ 起按 $\pi$ 的期望回报）ch2评价状态；$v_\pi(s)=\sum_{a'}\pi(a'\mid s)q_\pi(s,a')$ 中 $a'$ 是求和哑变量，不是当前采样动作 $A_t$
$q_\pi(s,a)$动作值（在 $s$ 取 $a$ 后按 $\pi$）ch2评价状态-动作对；不是即时奖励
$v^*,\ q^*$最优状态值 / 动作值ch3由 BOE 定义，与具体 $\pi$ 无关
$P_\pi$策略 $\pi$ 下的状态转移矩阵ch2行随机矩阵；$(I-\gamma P_\pi)$ 可逆
$r_\pi$策略 $\pi$ 下的期望奖励向量ch2—
$\alpha_k,\ \alpha_t$步长 / 学习率ch6RM 条件 $\sum\alpha=\infty,\ \sum\alpha^2\lt \infty$
$\bar q_t$TD target（统一视角）ch7不同算法换不同 $\bar q_t$（见 01 表5）
$\delta_t$TD error $=\bar q_t-q_t$ch7在 ch10 又当 advantage 的估计用
$w$值函数近似参数ch8拟合 $v/q$，与策略参数 $\theta$ 分开
$\theta$策略参数ch9拟合 $\pi$ 或 $\mu$；别和 $w$ 混
$J(\theta)$策略优化目标ch9可为 $\bar v_\pi$ 或 $\bar r_\pi$
$\mu(s,\theta)$确定性策略（直接输出动作）ch10不是概率分布，无 $\ln\pi$ 项
$A(s,a)$advantage $=q(s,a)-v(s)$ch10「比平均好多少」；减 baseline 得来
$\beta$行为策略（off-policy）ch10target $\pi$ ≠ behavior $\beta$

★ 最容易混的一组：各种状态分布#

符号含义用在哪
$d_0$固定的初始状态分布（人为指定）ch9 Theorem 9.2
$d_\pi$策略 $\pi$ 的平稳分布（长期停留比例）ch8 平稳分布、ch9 Theorem 9.3
$\rho_\pi$折扣状态访问分布（带 $\gamma^k$ 加权的总访问强度）ch9 Lemma 9.2、ch10
$\eta$推导中对状态加权的统称（视目标而定为 $d_0/d_\pi/\rho_\pi$）ch9/ch10 通用记号

这四个都是「状态上的权重」，区别只在怎么加权。读策略梯度公式时，先认清当前用的是哪一个，公式立刻清晰。

二、跨章易错点汇总#

#易错点真相章节
1$\mathcal A(s)$ 带括号是笔误故意的——动作空间原则上依赖状态；本书为统一才规定都用同一套 5 动作ch1.2
2进禁区会被墙弹回本书设定禁区可进入，只吃负奖励（更一般）ch1.3
3知道地图也要用 RL知道地图就退化成路径规划；RL 的前提是对环境一无所知ch1.1
4智能体追求即时最大奖励追求的是长期折扣回报 $G_t$ 的期望ch1.5–1.6
5$v$ 和 $q$ 混用$v$ 评价状态、$q$ 评价状态-动作；选动作要靠 $q$ch2.8
6BOE 也能像 BE 那样求逆BOE 带 $\max$ 非线性，不能求逆，只能迭代ch3.3.4
7必须每步给负奖励才不绕路不一定；仿射变换不改最优策略，绕路代价来自折扣ch3.5.6
8值迭代里 $v_k$ 就是状态值$v_k$/$q_k$ 是迭代中间量，未收敛前不是真正的 $v_\pi$/$q_\pi$ch4.1
9model-based/free 等于 on/off-policy两个独立维度：一个问「要不要模型」，一个问「采样=目标策略吗」ch4.5
10first-visit 与 every-visit 差别很大大样本下都收敛到同一 $q$；差别在样本利用方式ch5.3
11ε-greedy 的最优解 = greedy 最优ε>0 时最优 ε-greedy 策略可能与 greedy 最优不一致ch5.5
12第 6 章和正文关系不大可略过它是 ch7/8/9/10 收敛性的统一地基（RM/Dvoretzky/SGD）ch6
13on-policy = online两回事：on/off 问采样策略是否=目标策略；on/offline 问是否边交互边更新ch7.4
14Q-learning 目标策略也该 ε-greedyoff-policy：行为策略探索，目标策略可纯 greedych7.7
15DQN 的 loss 降到 0 就学好了loss=0 不代表价值估计正确（可能拟合了错误 target）ch8.4.6
16表格法和函数近似是两套东西表格是函数近似的特例（one-hot 线性，Box 8.2）ch8
17$v_\pi(s)$ 展开式里有 $a$，所以不能当 state-only baseline错：$v_\pi(s)=\sum_{a'}\pi(a'\mid s)q_\pi(s,a')$ 里的 $a'$ 是被求和平均掉的哑变量；固定 $s$ 后它不随当前样本动作 $A_t$ 变化ch10.2
18确定性策略梯度 = 把随机公式里 $A$ 换成 $\mu(S)$错：随机公式核心项 $\nabla_\theta\ln\pi(A\mid S,\theta)$ 在确定性策略里根本不存在；必须从 $v_\mu=q_\mu(s,\mu)$ 用链式法则重推ch10.4
19critic 打完分就结束critic 估计会改变 actor 方向，actor 又改变 critic 的目标分布；难点在两者同时更新的稳定性ch10.5
